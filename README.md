front page: **THE WORLD TODAY**.

## The day's news on the page

- **Lead — Gulf in flames:** the US strikes an Iranian missile site on
  Qeshm Island; Iran fires drones at US bases in Bahrain and Kuwait.
- **War in Ukraine:** Ukraine hits the Kerch bridge for a second day; part
  of the road span collapses into the strait.
- **Diplomacy:** Trump in Shenzhen and Manila; a Trump–Xi–Putin summit in
  Shenzhen on Thursday.
- **US politics:** Democrat Mary Peltola wins the Alaska Senate race;
  Democrats reach a 56–44 majority.
- **Health:** the Ebola outbreak in DR Congo passes 11,000 cases, 5,400
  deaths; children bear the heaviest toll.
- **Space:** Voyager 1 reaches one light-day from Earth, about 16 billion
  miles out — the first human-made object to do so.
- **Also today:** the US loses measles elimination status after 26 years
  (5,412 cases in 2026); Category 5 Cyclone Xavier hits the Northern Cook
  Islands; Nvidia posts a record $115.8B revenue; a Russian military plane
  crashes in Siberia, 19 dead.

## How it is built

`entry.png` (1024×1024, drawn programmatically in the build session with
crisp vector-style shapes and real text, so every headline stays legible)
is copied to `/output/entry.png` by `main.ts` (Node 22, standard library
only). The program runs with no network and writes identical bytes on
every run.

Run it as the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
